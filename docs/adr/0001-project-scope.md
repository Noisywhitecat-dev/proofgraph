# ADR-0001: 주제 선정과 중심축

- **날짜:** 2026-11-16
- **상태:** 승인
- **관련 단계:** 0단계 이전 (기획)

## 맥락
취업 준비와 동시에 진행하면서 백엔드와 프론트엔드, 여러 언어를 학습하고, 취업 증빙으로 쓸 수 있는 프로젝트가 필요했다.
Claude Code(Max 요금제)를 최대한 활용하되, Claude 혼자서는 완성할 수 없고 사용자의 판단이 반드시 필요한 규모여야 했다.
처음 후보였던 "취업 준비 플랫폼"과 대안 5개(코드 채점, 대중교통 데이터, 티켓팅, 협업 노트, 개인 지식 RAG)를 비교했다.

## 결정
개인 지식 RAG(E안)를 메인으로 하되, 중심축을 **"학습 저장소"에서 "취업을 위한 증빙과 판단 엔진"으로** 옮긴다.
모든 기능은 "지금 어떤 포지션에 얼마나 준비되어 있고, 어떻게 증명하며, 다음에 무엇을 할 것인가"라는 질문에 기여해야 한다.
데이터의 중심 구조는 기술(Skill)을 중심으로 한 지식 그래프다.

## 검토한 대안
| 대안 | 장점 | 단점 | 선택하지 않은 이유 |
|---|---|---|---|
| 취업 준비 플랫폼 (원안) | 동기 부여 | 기존 서비스와 겹침, 실사용자 확보 어려움 | 차별점이 약함 |
| 코드 채점 플랫폼 | 언어 다양성이 본질, 코딩테스트 준비와 결합 | 내 경력 증빙과의 연결이 약함 | 사용자가 E안을 선택 |
| 학습 메모장형 RAG | 구현이 쉬움 | 저장과 조회 중심, 기술적 깊이 부족 | 메모장이 됨 |

## 결과
- 실사용자 확보는 목표에서 제외한다. 현실 검증은 나의 실제 취업 활동, 진짜 데이터, 부하·장애 실험으로 한다.
- 범위가 넓어지는 위험이 있다. 1단계는 내 데이터와 증빙 그래프에만 집중하고, 뉴스와 동향은 4단계로 미룬다.
- 다시 검토할 조건: 1단계가 끝났는데 공개 프로필이 일반 포트폴리오 사이트와 차별점이 없을 때.

## 면접에서 설명한다면
"취업 준비를 하면서 제 학습과 프로젝트가 채용 시장의 요구와 얼마나 맞는지 판단할 도구가 필요했습니다. 그래서 모든 주장에 증빙이 연결되는 지식 그래프를 중심으로, 공고와의 갭을 분석하고 회사별 맞춤 포트폴리오를 만드는 시스템을 설계했습니다. 단순 노트 앱이 되지 않도록 '저장인가, 판단인가'를 기능마다 기준으로 삼았습니다."
