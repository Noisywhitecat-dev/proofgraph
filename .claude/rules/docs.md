# 문서 작성 규칙

- 문서는 한국어로 쓴다. 코드, 명령, 파일 경로는 백틱(`)으로 감싼다.
- 사용자는 개발 입문자다. 처음 나오는 용어는 문서 안에서 한 번 풀어 쓰고, `docs/glossary.md`에 한 줄로 추가한다.
- `docs/STATUS.md`는 30줄 이내로 유지한다. 자세한 내용은 ROADMAP, ADR, 학습 로그로 보낸다.
- ADR은 `docs/adr/0000-template.md` 구조를 그대로 따른다. 번호는 기존 최대 번호 + 1, 네 자리.
- 학습 로그 파일 이름은 `YYYY-MM-DD-주제.md`, 구조는 `docs/learning-log/README.md`의 템플릿을 따른다.
- 질문과 답은 `docs/QUESTIONS.md` 표에 기록하고, ID는 `P{단계}-{유형}{번호}` 형식으로 쓴다.
- 사용자의 경력이나 성과를 지어내지 않는다. 모르는 사실은 비워 두고 묻는다.
